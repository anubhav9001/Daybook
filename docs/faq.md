# Frequently Asked Questions

## Is Daybook free?
Yes, Daybook is free to download and use.

## Is the source code open?
No. The project is source-available on GitHub but is not open-source; see the repository for the exact terms.

## Which platforms are supported?
Windows 10 and 11 (64-bit). Other platforms are not currently supported.

## Where is my data stored?
Mail and calendar data stays with your Google or Microsoft 365 account. The built-in private AI runs locally.

## How do I report a bug?
Use [Report a Bug](https://github.com/anubhav9001/Daybook/issues/new/choose). Include your Daybook version, OS version, and reproduction steps.

## Where can I ask questions?
Open a thread in [Discussions](https://github.com/anubhav9001/Daybook/discussions).
