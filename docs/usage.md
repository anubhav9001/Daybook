# Using Daybook

Full guides live in the [Wiki](https://github.com/anubhav9001/Daybook/wiki). This page is a quick tour.

## First-time setup

1. Sign in with your Google or Microsoft 365 account.
2. Grant mail and calendar permissions.
3. Choose whether to enable the built-in private AI.

## Daily tasks

- **Read mail** — unified inbox view
- **Manage calendar** — view, create, update events
- **AI assist** — summarise threads, draft replies

For keyboard shortcuts, accessibility notes, and advanced configuration, see the [Wiki](https://github.com/anubhav9001/Daybook/wiki).
