## Daybook 0.5.2

Choose any model your cloud AI provider offers.

### New
- **Model list for cloud AI.** In **Settings › AI provider**, choose **Show available models**. Daybook asks your provider which models your API key can use and lists them all, newest first, with how much text each accepts. This works for Google Gemini, OpenAI, Anthropic, Groq, OpenRouter (free models listed first), Cerebras, SambaNova, Mistral, and Hugging Face.
- **Fewer tokens, faster replies.** Pick a lighter or older model, such as a Flash-Lite, mini, or small model, to stay within free limits longer and get quicker suggestions. Larger models write better replies.
- If a key is already saved, the list loads by itself when you open Settings. Choose **Other model** to type any model name. Microsoft Foundry still uses your own deployment name.
- Your API key is only ever sent to its own provider, from a fixed address.

### Good to know
- The installer is still unsigned, so Windows SmartScreen may warn. Choose **More info › Run anyway**.

Install `Daybook-Setup-0.5.2.exe` below. If you already have Daybook installed, it will offer this update automatically.
